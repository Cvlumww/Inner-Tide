# CMS editor guide

The WordPress dashboard controls published Blog, News, and Services content on
the public Next.js site. Changes normally appear within an hour; when the
revalidation secret is configured, publishing triggers an immediate refresh.

## Blog articles

1. Go to **Posts → Add New**.
2. Add a clear title, body, short excerpt, and featured image.
3. Use Yoast SEO to set a useful search title and description.
4. Preview the copy in WordPress, then publish it.

The article appears on `/blog` and at `/blog/{post-slug}`. Keep the generated
slug short and descriptive. Changing a slug after publishing changes the public
URL and should be paired with a redirect.

## News

News uses the same editor and detail template as Blog articles. To add an item
to `/news`, select the category named **News** (slug `news`) before publishing.
The article retains one canonical URL under `/blog/{post-slug}` so search
engines do not see duplicate copies.

## Services

Go to **Services → Add New**, then complete:

- **Title**, main editor, excerpt, and featured image;
- **Summary** for the introduction;
- **Benefits**, one concise point per row;
- **Who it is for**;
- **Duration** and display **Price**;
- **Booking button label** and **Booking URL**;
- optional gallery;
- **Feature this service** to show it on the homepage.

Use the **Order** field in Page Attributes to control the Services archive.
Lower numbers appear first. Complete the Yoast title and description before
publishing.

## Images and accessibility

- Use sharp landscape images for featured images; avoid uploading files larger
  than needed.
- Fill in alternative text that describes the useful content of the image.
- Do not put essential text inside an image.
- Only upload media the studio owns or is licensed to use.

## SEO and factual accuracy

Write for people first. Use one descriptive page title and a specific summary;
do not repeat keywords unnaturally. Confirm claims, prices, dates, addresses,
and booking links before publishing. Structured data and the AI discovery file
are generated by the frontend from this verified content.

## Troubleshooting

If content does not appear:

1. Confirm the item is **Published**, not Draft or Private.
2. Confirm News has the `news` category.
3. Confirm Services has all required ACF fields.
4. Check the public URL after a minute.
5. Ask an administrator to verify `WORDPRESS_API_URL` and the matching
   revalidation secrets if the issue persists.
